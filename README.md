# YumBuddy — Smart Kid Nutrition

Мобильный React-интерфейс для планирования детского питания. Приложение хранит профиль ребёнка, дневник питания, воду, рецепты, избранное и дневные планы локально в браузере.

## Возможности

- профиль ребёнка и персональные параметры;
- каталог и подбор рецептов;
- план питания на день;
- дневник приёмов пищи и воды;
- избранные рецепты;
- адаптивная навигация, рассчитанная на мобильный экран;
- локальное хранение данных без обязательного backend.

## Стек

- React + TypeScript + Vite;
- Tailwind CSS и shadcn/ui;
- React Router;
- TanStack Query;
- Framer Motion;
- date-fns.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Данные и приватность

Текущая версия использует `localStorage`. Данные не синхронизируются между устройствами и удаляются при очистке хранилища браузера. Не используйте приложение как медицинскую систему или замену консультации специалиста.
